# STM32F407ZET6 电赛交互菜单页面说明

## 概述

本项目实现了基于 STM32F407ZET6 微控制器的交互式菜单界面，利用四个按键进行菜单项的选择、编辑与翻页操作。该项目支持多个页面，用户可以通过按键交互控制界面内容，调整参数并进行查看。

## 功能说明

### 按键功能

- **key1**  
  - **短按**: 切换到上一页  
  - **长按**: 切换到下一页
  
- **key2**  
  - **短按**: 向上选择菜单项  
  - **长按**: 向下选择菜单项
  
- **key3**  
  - **短按**: 增加当前选中项的数据  
  - **长按**: 减少当前选中项的数据
  
- **key4**  
  - **短按**: 设置当前项为活动项  
  - **长按**: 取消活动项

### 页面与项目

该系统实现了三种页面，每个页面包含多个项目。每个项目的数据可以被选择并修改。项目的数据可以是浮动数字值、角度等。

- **页面 1**  
  - 项目名称: `a`, `P`, `I`, `D`, `Angle`  
  - 数据: `num1`, `num2`, `num3`, `num2`, `num3`  
   
- **页面 2**  
  - 项目名称: `Speed`, `Angle`, `Position`, `Time`, `Error`  
  - 数据: `num1`, `num2`, `num3`, `angle`, `BIN`  

- **页面 3**  
  - 项目名称: `Current`, `Voltage`, `Power`, `Temp`, `Status`  
  - 数据: `num1`, `num2`, `num3`, `angle`, `BIN`

### 菜单项的增减功能

- **项目数据增加**  
  每个页面的项目数据（除 `Current_Step` 项外）可以通过按 `key3` 增加。

- **项目数据减少**  
  按住 `key3` 长按可以减少项目数据。对于 `Current_Step` 项，数据增减步长为 `STEP`，该值在页面间变化时，`STEP` 也会发生调整。

### 页面切换与光标移动

- **翻页功能**  
  用户可以通过短按或长按 `key1`、`key2` 实现页面间的切换与光标在项目间的上下移动。
  
- **光标显示**  
  当前选择的菜单项会用光标 `>` 或 `&` 标示，提示用户当前所选项。

### 屏幕显示

每次刷新屏幕时，系统会显示当前页面的标题、步长（Step）以及各项数据。菜单项通过光标标示，用户可以选择并修改相关数据。

## 代码说明

### 主要变量

- `Current_keyState`: 当前按键状态。可以是浮空、单击、双击或长按。
- `Active_Flag`: 标记当前选中项是否为活动项。
- `Cursor_position`: 当前光标的位置。
- `refresh_Flag`: 页面是否需要刷新。
- `Page_number`: 当前页面编号，取值范围 [0, 2]。
